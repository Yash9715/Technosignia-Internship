# Technosignia Internship – Data Analytics

**Internship Repository | 15 Days of Practical Learning**

## About This Repository

This repository contains my daily tasks, practical exercises, Python programs, datasets, Jupyter Notebooks, data analysis work, and project deliverables completed during my 15-day Data Analytics Internship at Technosignia.

The internship focuses on developing practical skills in Python programming, data analysis, data visualization, SQL, statistics, and machine learning fundamentals.

## Internship Objectives

- Understand Data Analytics and Data Science concepts.
- Learn Python programming and problem-solving.
- Perform numerical computing using NumPy.
- Load, explore, and clean datasets using Pandas.
- Analyze data and identify meaningful patterns.
- Create visualizations using Matplotlib and Seaborn.
- Understand SQL and statistical concepts.
- Learn basic Machine Learning workflows.
- Use GitHub for version control and project documentation.
